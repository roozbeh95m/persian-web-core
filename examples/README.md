# Examples

These scripts demonstrate real `@persian-web/core` APIs for common Persian / Farsi web development tasks.

Build first (or use `npm run examples`):

```bash
npm run build
node examples/quick-start.mjs
node examples/jalali-date.mjs
node examples/persian-numbers.mjs
node examples/rtl-and-typography.mjs
node examples/iranian-forms.mjs
```

Imports resolve against the local `dist/` build so you do not need a published install to try them.
